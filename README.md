# 3D 列印機器原理教學

依《3D列印機器原理.pdf》整理的繁體中文圖解講義，包含九個主題、八張原稿裁圖、對照表與課堂複習。

## 閱讀講義

- [圖解講義](output/handout/3D列印機器原理講義.md)：使用儲存庫內的相對圖片路徑，可直接在 GitHub 閱讀。
- [HackMD 線上講義](https://hackmd.io/KYyn9hZ1QmibLLlXRzqc1w)
- [原始 PDF](3D列印機器原理.pdf)
- [工作紀錄](agent.md)

## 主題

1. 機器結構總覽
2. 擠出頭工作原理
3. 從模型到成品的列印流程
4. 皮帶與螺桿運動系統
5. 關鍵組件與作用
6. X、Y、Z 座標系統
7. PLA、ABS、PETG 材料比較
8. 操作維護與常見問題
9. 重點總結與複習
